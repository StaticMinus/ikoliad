## ⭐️ 1. Default Workspace Design Architecture: Apple Clean + Bento Grid Supercharged

All projects, components, and interfaces in this workspace must default to the **"Apple Clean / Spatial Minimalist + Bento Grid Supercharged / Modular Hub"** visual design architecture:

### Visual Foundation & Rules:
1. **Canvas & Surfaces**:
   - Primary Canvas: Pure White (`#FFFFFF`) and Soft Cloud Gray (`#F5F5F7` / `#FAFAFA`).
   - Hairline Dividers: Ultra-subtle borders (`border-black/5` or `border-zinc-200/80`).
2. **Glass & Elevation**:
   - Frosted Light Glass: Translucent floating pill docks & capsules (`bg-white/80 backdrop-blur-xl border border-black/5 shadow-xs`).
   - Optical Elevation: Soft diffused shadows (`shadow-[0_8px_30px_rgb(0,0,0,0.04)]` or `shadow-sm`), avoiding harsh artificial glows.
3. **Bento Grid System**:
   - Dense, multi-sized modular Bento boxes (col-span-4, col-span-8, col-span-12).
   - Interactive micro-widgets, live status chips, metric progress bars, and high-res photography.
4. **Color Tokens**:
   - **Primary Canvas**: `#FFFFFF` / `#F5F5F7`
   - **Semantic Blue Accent**: `#0071E3` (Apple Blue)
   - **Ikoli Red**: `#DE322D` (Primary surveillance signal)
   - **Clinical Emerald**: `#10B981` (WHO target success indicator)
   - **Charcoal Text**: `#1D1D1F` (Primary), `#86868B` (Muted/Secondary)
5. **Typography Hierarchy**:
   - **Headlines & Body**: `Plus Jakarta Sans` / `SF Pro` / `Inter` (Humanist, fluid optical weight)
   - **Data & Telemetry**: `IBM Plex Mono` / Tabular Monospace
6. **Strict Anti-Pattern Rule**:
   - Do NOT default to pitch-black cards with neon-blue glowing borders. All primary interfaces must lead with this airy, breathable, hardware-polished modular Bento aesthetic.
